API introduction (Operation description & Interface information)   Interface document version : v2.0
🌟Operating Instructions
1. Instructions for receiving SMS
(1) Call interface [2.1/2.2] to get a phone number to use.
(2) If the number you got has been used or cannot be used for registration, please call interface [Add phone Number to blacklist] to blacklist the number, so as to make sure that this number will not appear again.
(3) If the number you got an available number, you can call interface [3] to request receive SMS code, please call the interface 1 times every 15 seconds (Cause SMS might arrive a bit slow for some projects). Each number is valid for 5 minutes. If there is still no SMS returned when you try many times, then please call interface [5] to add phone number to blacklist. If the SMS code is received successfully, you don’t have to blacklist the number.
(4) If SMS code is received successfully, you don’t have to call interface [4] Release the phone number or to call interface [5]Add phone Number to blacklist.
(5) In order to use the phone numbers on our platform more efficiently, you can call interface [8] to check the Countries Distribution and Quantity of the current online phone numbers.
(6) Please feel free to contact our on-line support if there is any question.
2. Tips
(1) After you got the phone number, please use it to register in time to ensure that the SMS Code can be received successfuly (Suggestion: use the number within 5-60 seconds since the phone number is valid 5 minutes, and it will be released automatically after timeout)
(2) Please note: the phone numbers you got are all with country code. You can remove or keep the phone number according to your needs (please find the country code list for reference below at the [2.1/2.2] interface).
🌟Interface information
Parameters: name: user name, ApiKey：API interface authentication token. (They are required parameters for all interface requests).
Interface encoding UTF-8, interface return value is json format
{
    "code": "", //return code
    "msg": "",  //return information
    "data": ""  //return data
}

2.1 Get/Occupy phone number
https://api.durianrcs.com/out/ext_api/getMobile?name=admin&ApiKey=12345678&cuy=bo&pid=123&num=5&noblack=0&serial=2&secret_key=null&vip=null

Friendly reminder: It is strongly recommended to wait for 5 seconds and then send SMS after you got the phone number.
name：username*
ApiKey：API interface authentication token* show
cuy：country code (two digits, not required, by default all countries) show
pex：Filter the number prefix. Format: 591738, country code (591, refer to cuy country code) + prefix (738), total length: 1-6 digits
pid：project ID*
num：Get the number of mobile phone numbers quantity (1-10)*
noblack：Filter blacklists rule (0, 1) : 0: Filter only self-added blacklists, 1: filter all user-added blacklists*
serial：Single or multiple (1: multiple, 2: single)*
secret_key：parameters required only for few special projects, please contact admin if you get a reminder that it is required, otherwise just leave it empty*
vip：VIP exclusive channel*
//Single data format
{
    "code": 200,
    "msg": "Success",
    "data": "+59173841704"
}
//Multiple data formats
{
    "code": 200,
    "msg": "Success",
    "data": [
        "+59173841704",
        "+59173841704"
    ]
}

//return value reference
200：Success
800：Account is blocked
802：incorrect username or ApiKey
803：Username or ApiKey cannot be empty
902：Incorrect parameter
903：invalid country code
904：Invalid project ID
906：number list is empty
907：Vipkey error
400：Failure, system exception
403：Insufficient credits balance, please recharge to continue
406：New numbers obtained in 24 hours has reached the maximum amount. Please contact administrator to upgrade your account level to increase new numbers access or continue to get old numbers
409：The request frequency is too high, please check your code or contact the administrator
400101：This project requires secret key, please contact the administrator
400102：The parameters specified are not open, please contact the administrator
400103：secret_ Key error
400906：Invalid series or series parameter error
200408：The phone numbers cards amount has reached the upper limit, please contact the administrator to increase more numbers
Note: You can call Interface 2.1 OR Interface 2.2 to get a phone number. Interface 2.1 and Interface 2.2 are the same in purpose and usage. The difference is that they return different data formats： Interface 2.1 directly returns the phone number; Interface 2.2 returns the phone number and the country code of this phone number.
